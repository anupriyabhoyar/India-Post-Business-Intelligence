# India Post Business Intelligence

Business Intelligence project for cleaning, analyzing, and visualizing India Post Office Directory data using SQL and Power BI.

## 🎯 Objective

To analyze postal office coverage, delivery status, service gaps, and data completeness using a BI dashboard.

## 🛠️ Tools Used

- MySQL
- Power BI
- Power Query
- CSV Dataset

## 📊 Key Analysis

- Total Post Offices
- Delivery vs Non-Delivery Offices
- State-wise Post Office Distribution
- Delivery Coverage
- Contact Data Completeness
- Service Gaps by State
